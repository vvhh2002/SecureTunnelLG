# LG 虚拟机镜像规划

**尚未实现镜像生成器，也没有可启动的虚拟机镜像。**

规划采用裁剪后的 **Debian 13（trixie）**，提供 `qcow2` 与 `raw` 磁盘镜像，首期目标架构为 `x86_64` 和 `aarch64`。具体虚拟化平台、启动方式与网络配置仍需验证。

嵌入式设备需要对应板卡的启动与驱动支持；虚拟机镜像不能直接视为可刷写的板级镜像。SD/eMMC 安装方式、资源用量及最低内存要求尚未完成实机验证。

交付目标包括开机自动提供 Web 管理、每设备独立随机生成的 `admin` 初始密码、首次登录强制改密，以及重启和升级后保留配置。克隆为新设备时应生成独立身份和凭据。这些功能目前均待实现。

LG 的办公室动态公网部署还需要 DDNS、真实公网入站能力及必要的端口映射。参见 [项目首页](../../README.md)、[Web 管理规划](../../docs/web-management.md) 与 [自启说明](../systemd/README.md)。
