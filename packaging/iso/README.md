# LG ISO 安装介质规划

**尚未实现安装器或 ISO 生成器，目前没有可引导安装介质。**

规划采用裁剪后的 **Debian 13（trixie）**，首期考虑 `x86_64` UEFI 安装环境。`aarch64` 也是目标架构，但不承诺通用可启动 ISO，需按具体设备确定安装方式。

嵌入式板卡的 SD/eMMC 镜像与通用 ISO 不同，需要逐板验证启动、内核、驱动及资源用量。当前尚无已验证的板卡兼容清单或最低内存要求。

未来安装流程应明确展示目标磁盘及数据清除影响，在用户确认后写入。设备身份应独立建立，`admin` 初始密码应在每台设备上随机生成，不能使用通用密码；首次登录必须改密并重新登录。安装完成后自动提供管理入口、保存配置及故障恢复均为待实现目标。

LG 的动态公网部署需要 DDNS 与实际入站条件。参见 [项目首页](../../README.md)、[Web 管理规划](../../docs/web-management.md)、[虚拟机镜像规划](../vm/README.md) 与 [自启说明](../systemd/README.md)。
