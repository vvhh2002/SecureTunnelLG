# LG Docker 交付状态

**当前 Docker 镜像仅运行命令行开发验证程序，显示帮助或版本后退出；不提供 Web 管理、隧道连接或网关转发。**

基础镜像为 **Debian 13（trixie）** 的 `debian:trixie-slim`，目标平台是 `linux/amd64` 与 `linux/arm64`，分别对应 `x86_64` 与 `aarch64`。运行验证成功不等于已经具备可部署的网关功能。

未来网关容器需要受支持的 Linux 宿主及相应网络能力。容器共享宿主内核，更换基础镜像不会替换宿主内核；TUN、防火墙、连接跟踪、转发能力及设备驱动仍需验证。嵌入式板卡兼容性和最低内存尚未确定。

LG 的动态公网部署需要 DDNS 与真实公网入站能力。Docker 本身不能解决公网地址、端口映射或运营商网络限制。

独立 Web、持久账户与设备自启尚未实现。规划采用每设备随机初始密码和首次登录强制改密，容器更新后保留账户状态。当前不能把帮助命令配置成循环重启服务来代替网关。

参见 [项目首页](../../README.md)、[Web 管理规划](../../docs/web-management.md) 与 [自启说明](../systemd/README.md)。
