# LG 配置示例

[gateway.example.toml](gateway.example.toml) 用于展示预期配置，地址和接口均为示例值。**当前命令行程序不会读取、校验或应用此文件**，字段仍可能变化。

LG 的部署规划需要明确以下信息：

- 公网域名与接入端口；动态公网 IP 需要 DDNS，并验证真实入站能力、端口映射和防火墙规则。DDNS 不能解决没有公网入站能力的问题。
- 允许接入的远端节点及经可信渠道核验的身份。示例中的外部前置网关需要单独配置。
- 允许访问的来源、目标与具体协议；LG 的访问范围不能超出远端网关批准的范围。
- 与现网不冲突的链路地址和路由，以及管理员的访问方式。

Web 管理规划默认只监听本机 `127.0.0.1`，远程管理员通过已配置的可信 SSH 转发访问。目前尚无可用的 Web 服务或自动网络配置功能。

参见 [项目首页](../README.md) 与 [Web 管理规划](../docs/web-management.md)。
