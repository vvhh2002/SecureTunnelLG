# LG Web 管理规划

**以下均为待实现的产品功能。目前没有可登录的管理页面，也未提供开机自启。**

LG 管理界面面向本地网关管理员，与远端网关的账户和管理界面独立。规划提供以下能力：

| 功能 | 用户可以完成的操作 |
| --- | --- |
| 总览 | 分别查看连接状态、配置状态和实际业务可达性 |
| 公网入口 | 设置域名与接入端口，检查 DDNS、端口映射和公网入站条件 |
| 接入节点 | 登记可信远端节点，核验身份，停用或撤销访问 |
| 访问策略 | 指定允许的来源、目标和协议，查看远端授权限制 |
| 变更 | 保存草稿、检查影响、应用并确认配置，失败时恢复安全状态 |
| 诊断 | 查看故障原因、版本和存储状态，导出脱敏诊断信息 |

连接显示在线不等于业务已经可用，界面应分别报告各项检查结果。LG 不能扩大远端网关本机批准的访问范围。动态公网地址变化后应恢复连接；身份发生变化时必须重新核验，不能自动忽略。

## 首次访问

管理入口规划默认只监听设备本机 `127.0.0.1`。远程管理员通过已配置的可信 SSH 转发访问；首次访问不能依赖尚未建立的网关连接。

1. 安装或出厂配置为每台设备随机生成独立的 `admin` 初始密码，通过可信渠道交付。该账户仅用于 Web 管理，不是系统或 SSH 登录账户。
2. 初始密码验证成功后，只能修改本人密码或退出，不能查看或操作管理功能。
3. 新密码成功保存后注销旧会话，必须使用新密码重新登录；原初始密码失效。
4. 完成节点身份核验与接入配置，再按远端已批准的范围建立访问策略。首次登录和改密不会自动放通业务。

管理员与只读用户均可修改自己的密码；只读用户不能变更网络配置。密码和首次改密状态应跨重启、升级及容器重建保存，认证数据丢失或损坏时不能自动重建默认账户。

## 配置与故障处理

保存草稿不改变网络。应用前应显示检查结果和受影响范围；应用后要求在限定时间内确认，失败或超时应恢复安全状态。已经撤销的访问权限不能因恢复旧配置而重新生效。

设备开机后应自动提供管理入口，无须用户手动启动。无外网或远端离线时，只要本机认证存储正常，仍应能够登录和完成首次改密；正常登录后可查看故障原因。管理页面恢复不应中断既有隧道。

上述账户、配置恢复与自启能力均尚未实现或完成设备验收。当前状态见 [项目首页](../README.md) 与 [自启说明](../packaging/systemd/README.md)。
